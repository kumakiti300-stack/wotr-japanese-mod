# Pathfinder: Wrath of the Righteous 日本語翻訳MOD

本編・DLCの会話、クエスト、説明文、名称・UIを日本語で遊ぶための非公式日本語翻訳MODです。

**公開版 v0.1.2です。** [Releases](https://github.com/kumakiti300-stack/wotr-japanese-mod/releases)から `wotr-japanese-mod-v0.1.2.zip` を取得してください。
翻訳データはReleasesの配布ZIPにまとめています。このリポジトリでは、導入案内とツールを公開しています。

## 導入

Windows・ゲーム版2.7.0xのデータが対象です。**日本語表示には、別途フォント設定が必要です。** 初めて日本語化する場合は、先に[日本語フォントの導入手順](docs/INSTALL.md#日本語フォントについて)を確認してください。フォント・Unity Mod Manager・第三者MODは同梱していません。

1. 日本語翻訳MODのZIPを**すべて展開**します。
2. ゲームを終了して**「日本語を導入.cmd」**を開き、「日本語を導入」を押します。Steamのゲームフォルダは自動で探します。見つからない場合だけ「選択...」から指定してください。
3. ゲームを起動し、言語を**「简体中文」**に変更します。

翻訳の導入にPythonや手動コピーは不要です。このツールで初めてファイルを置き換える際にバックアップします。ツールで保存した翻訳ファイルを戻すには**「元に戻す.cmd」**を開いてください。フォントの導入・復元は別の操作です。

[詳しい導入・復元手順](docs/INSTALL.md)

### おまけ：クエスト更新通知の表示修正

画面上部のクエスト更新通知で文字が消える場合に使える `QuestNotificationFontFix` 1.2.1を、`extras/` におまけとして入れています。 必要な人だけ[導入方法](extras/QuestNotificationFontFix/README.md)を見て使ってください。Releasesから、おまけのZIPだけ取得することもできます。

### 手動で導入する場合

ゲームを終了し、元の `zhCN.json` を別の場所へバックアップしてから、ZIP内の `translations\zhCN.json` を次の場所へコピーして置き換えます。

~~~text
ゲームフォルダ\Wrath_Data\StreamingAssets\Localization\zhCN.json
~~~

ゲームフォルダはSteamライブラリで本作を右クリックし、**「管理」→「ローカルファイルを閲覧」**で開けます。配置後は言語を「简体中文」にしてください。[標準パスの例・手動で戻す方法](docs/INSTALL.md#手動で導入する)

## 他の翻訳MODとの競合

同じ `zhCN.json` を置き換える翻訳MODとは併用できません。初回の置換時は、その時点のファイルをバックアップします。自動併合は行わず、導入後に別のツールで変更した場合は自動更新・復元を拒否することがあります。

## 既知の制限

本翻訳はAI(GPT-6.1 Sol)を使って作成・原文対照しています。通しプレイは1回実施していますが、すべての文章を校閲したわけではなく、全ルートを通しての確認もまだです。原文不足などで確定できていない箇所もあります。ゲーム版やMODの組み合わせによって、制作環境と違う動作になる場合がありますのでご了承ください。

## 不具合報告・一般連絡

不具合報告と一般連絡には[GitHub Issues](https://github.com/kumakiti300-stack/wotr-japanese-mod/issues)を利用できます。ゲーム版、使った配布ファイル、導入方法、発生場所・表示文・再現手順を分かる範囲で記載してください。画像やログに個人情報が含まれないか確認してください。

個人で作っているMODなので、すべてへの返信や修正はお約束できませんが、いただいた報告は参考にします。

## 自分で直して使う

気になる言い回しなどがあれば、使いやすいように手を入れてもらって構いません。こちらへの確認や連絡は不要です。編集した翻訳は[手動で導入](docs/INSTALL.md#翻訳を自分で直す)してください。GUIDや変数・タグは残して、編集前のファイルも保存しておくと安心です。

元ゲームや参考にした資料の出典は[NOTICE.md](NOTICE.md)にまとめています。
