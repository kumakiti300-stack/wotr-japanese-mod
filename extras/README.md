# おまけ：クエスト更新通知の表示修正MOD

`QuestNotificationFontFix` は、画面上部に出るクエスト更新通知の文字が消える場合に使える、おまけの補助MODです。すでに通知が読める環境では、入れなくて大丈夫です。

この翻訳の制作時に作成した補助MODで、UMMと `I18NFont4UnityGame-UMM` を別途導入した環境で使います。**「日本語を導入.cmd」からは自動導入されません。** [導入・削除・確認方法](QuestNotificationFontFix/README.md)を読んでから使ってください。

DLL、UMM用の設定、ソースコード、MIT Licenseを同梱しています。ゲームのDLL、フォント、UMM、第三者のフォントMODは同梱していません。

**制作環境では、ゲーム内でクエスト更新通知の文字が表示されることを確認済みです。** 使いやすいように手を入れてもらっても構いません。こちらへの確認や連絡は不要です。
