# 日本語翻訳MODの導入

Windows・ゲーム版2.7.0xのデータを対象にした公開版 v0.1.2です。[本MODのReleases](https://github.com/kumakiti300-stack/wotr-japanese-mod/releases)から `wotr-japanese-mod-v0.1.2.zip` を取得してください。「Source code」のZIPとは別です。

初めて日本語化する場合は、先に[日本語フォントの準備](#日本語フォントについて)を行ってください。すでに日本語が表示できている場合は、その設定を利用できます。

## 導入ツールで導入する

1. ゲームを終了します。
2. 日本語翻訳MODのZIPを右クリックし、**「すべて展開」**します。
3. 展開したフォルダの**「日本語を導入.cmd」**を開き、**「日本語を導入」**を押します。
4. ゲームを起動し、言語を**「简体中文」**に設定します。

Steamのライブラリを調べてゲームフォルダを自動検出します。複数ある場合やSteam以外の版では、「選択...」から `Wrath.exe` があるフォルダを選んでください。別のドライブにあるSteamライブラリも対象です。

このツールで初めてファイルを置き換える際に、直前のファイルをゲームフォルダ内の `WotR-Japanese-Backup` に保存します。このフォルダは、元に戻す場合に必要です。別の翻訳を導入済みなら、その時点のファイルを保存して置き換えます。翻訳同士の自動併合は行いません。

同じ翻訳がすでに手動配置されている場合は置換せず、新しいバックアップも作りません。その場合、元に戻すには手動導入前に保存したファイルが必要です。

## 翻訳を更新する

新しいZIPを別のフォルダへ展開し、同じ「日本語を導入.cmd」を実行します。初回導入前のバックアップは上書きしません。同じ版が入っている場合は、その旨を表示します。

このツールのバックアップ履歴と一致しない変更が見つかった場合や、対応データと一致しない場合は上書きせずに止まります。対応判定にはゲームの `enGB.json` のSHA-256を使うため、表示上の版名が2.7.0xでもデータが異なれば止まります。

## 元に戻す

ゲームを終了して**「元に戻す.cmd」**を開き、**「導入前に戻す」**を押します。このツールで初めて導入した直前のファイルに戻します。バックアップは復元後も残します。

このツールで作ったバックアップがない場合は、別途保管していた元のファイルを手動で復元してください。ゲーム更新で版が変わった場合は、古いバックアップを自動で適用しません。

復元するのは翻訳ファイルだけです。別途導入したフォントやUMMを戻す場合は、それぞれの配布元の手順に従ってください。

## 日本語フォントについて

このZIPにはフォント、Unity Mod Manager（UMM）、第三者のフォントMODを同梱していません。以下は[既存の日本語化手順](https://github.com/Eniwder/pathfinder_Japanese_translation/blob/main/pathfinder_jp/導入手順.txt)と[UMM対応フォントMOD作者の案内](https://forum.gamer.com.tw/Co.php?bsn=32327&sn=1258&subbsn=1&bPage=0)に基づく方法です。配布元の条件と手順も確認してください。

1. ゲームを終了し、[Unity Mod Managerの配布元](https://www.nexusmods.com/site/mods/21)からUMMを取得します。UMMの「Install」タブで本作と `Wrath.exe` があるゲームフォルダを指定し、導入します。
2. 上記のフォントMOD作者の案内から、**WotR用のUMM対応版** `I18NFont4UnityGame-UMM-PathfinderWotD.zip` を取得します。UMMの「Mods」タブで、そのZIPを展開せずに読み込んで導入します。同名のBepInEx用プラグインとは導入先が異なります。
3. 日本語向けの字形にする場合は、[Eniwder氏の配布物](https://github.com/Eniwder/pathfinder_Japanese_translation/releases)にある `fonts/medium/source_han_sans` などを利用できます。元のファイルをバックアップしてから、ゲームフォルダの `Mods/I18NFont4UnityGame-UMM/source_han_sans` に配置します。取得した配布物の翻訳JSONはコピーせず、本MODの `translations/zhCN.json` を使ってください。
4. `Mods/I18NFont4UnityGame-UMM/config.json` に `ShouldOverrideAscii` がある場合は **`false` を維持**してください。既存環境では `true` にすると通常の文字が消えました。フォントの配置後はゲームを完全に再起動します。

クエスト更新通知の文字が消える場合は、[おまけの補助MOD](../extras/QuestNotificationFontFix/README.md)を使えます。制作環境では、この補助MODを入れてゲーム内の通知に文字が表示されることを確認済みです。すでに問題なく表示できていれば、今の設定のままで大丈夫です。

## 手動で導入する

翻訳ファイルをゲーム本体の `Localization` フォルダへ直接配置します。CMDを実行せずに導入できます。

1. ゲームを終了し、ZIPを**すべて展開**します。
2. Steamのライブラリで **Pathfinder: Wrath of the Righteous** を右クリックし、**「管理」→「ローカルファイルを閲覧」**を選びます。`Wrath.exe` があるゲームフォルダが開きます。
3. そこから **`Wrath_Data` → `StreamingAssets` → `Localization`** と開きます。
4. 中にある **`zhCN.json` を別の場所へコピーしてバックアップ**します。保存先は、例えば自分で作った「WotR翻訳バックアップ」フォルダです。
5. ZIPを展開したフォルダの **`translations\zhCN.json`** を、手順3の `Localization` フォルダへコピーし、既存の `zhCN.json` を置き換えます。
6. ゲームを起動し、言語を **「简体中文」** に変更します。

コピー元とコピー先は次の対応です。

~~~text
コピー元: ZIP展開先\translations\zhCN.json
コピー先: ゲームフォルダ\Wrath_Data\StreamingAssets\Localization\zhCN.json
~~~

Steamを標準の場所にインストールしている場合のパス例です。

~~~text
C:\Program Files (x86)\Steam\steamapps\common\Pathfinder Second Adventure\Wrath_Data\StreamingAssets\Localization\zhCN.json
~~~

ドライブやSteamライブラリの場所を変更している場合は、パスの先頭が異なります。実際の保存先はSteamから開いたゲームフォルダで確認してください。Steam以外の版では、インストール先の `Wrath.exe` があるフォルダから同じ構成をたどります。

### 手動導入後の更新・復元

更新するときは、新しいZIPの `translations\zhCN.json` を同じ場所へコピーします。初回導入前に保存したバックアップは残してください。

元に戻すときはゲームを終了し、保存しておいた `zhCN.json` を同じ `Localization` フォルダへコピーして置き換えます。手動で保存したバックアップは手動で復元します。「元に戻す.cmd」は導入ツールが作成したバックアップを使います。

## 翻訳を自分で直す

気になる言い回しなどがあれば、手元で直して使ってもらって構いません。こちらへの確認や連絡は不要です。

1. 配布版の `translations/zhCN.json` を別の作業フォルダへコピーし、編集前のファイルも保存します。
2. UTF-8を扱えるエディターで、`strings` 内の表示文字列を変更します。GUID、JSONの構造、`{name}` などの変数や装飾・用語リンクのタグは保持し、JSONとして読み込める状態で保存します。
3. **編集するとハッシュが変わるため、「日本語を導入.cmd」は修正版を導入できません。** ゲームを終了し、ゲーム側の現在の `zhCN.json` を別の場所へバックアップしたうえで、上記の[手動導入](#手動で導入する)と同じコピー先へ修正版を配置します。
4. 元に戻す場合はゲームを終了し、手順3で保存したファイルを手動で戻します。修正版を配置した状態では「元に戻す.cmd」が未登録の変更として停止することがあります。

配布版のインストーラーとチェックサムは、編集前のデータに対応します。手を入れた後の表示や動作は、手元の環境で確認しながら使ってください。

## 不具合報告・一般連絡

うまく動かない場合は、ゲーム版・導入先・言語・フォント設定を確認してみてください。困ったときはバックアップから戻せます。気になることがあれば、使った版と状況を添えて[GitHub Issues](https://github.com/kumakiti300-stack/wotr-japanese-mod/issues)へどうぞ。すべてへの返信や修正はお約束できませんが、報告は参考にします。
